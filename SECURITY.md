# Security

gpu.nz Code is a desktop coding agent built on OpenCode. This file is about the gpu.nz Code app; the security
decisions behind it are described in [GPUNZ.md](GPUNZ.md#security-decisions-review-of-2026-11-12).

## Reporting a problem

Write to **admin@gpu.nz** with the subject «Security». Please do not open a public issue for something that can be
used against other people before it is fixed. Say what you did, what happened and what you expected; a proof of
concept helps. We answer within a few working days.

## What the app is and is not

- **The agent is not sandboxed.** It runs commands and edits files on your computer with your rights. The questions
  it asks before destructive commands are a speed bump against a model led astray by text it read, not a security
  boundary. For real isolation run it in a virtual machine or a container.
- **A folder you open is trusted** with its own configuration (MCP servers, plugins), as in OpenCode. Do not open
  folders you do not trust.
- **Your account key** is kept in the operating system's keychain and is sent only to `https://gpu.nz`. The key of
  a rented server goes only to `https://*.run.gpu.nz`.
- **Updates** are installed only when their manifest carries a valid signature of our release key
  (`packages/desktop/src/main/gpunz/release.ts`).

## Out of scope

- What the agent does when you tell it to, or approve it.
- Problems of the upstream project that are not specific to our changes — report those to
  [OpenCode](https://github.com/anomalyco/opencode/security).
- Reports generated by a tool and not checked by a person.
